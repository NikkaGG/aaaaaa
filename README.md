# CameraOverride — фикс сломанной 1x камеры для Instagram

Самописный LSPosed-модуль: прячет ID сломанной 1x камеры для пакета
`com.instagram.android`, оставляя доступной только 0.5x (ultrawide).

## Перед сборкой

1. Поставь приложение **Camera2 API Probe** (Google Play) и посмотри реальный
   список камер и их характеристики (facing / focal length) на своём Poco X4 Pro 5G.
2. В файле
   `app/src/main/java/com/example/cameraoverride/CameraOverride.kt`
   поправь константу `BROKEN_CAMERA_ID`, если у тебя не "0".

## Сборка

Готовой скомпилированной программы (APK) я собрать не могу — здесь нет
Android SDK/эмулятора с доступом к нужным репозиториям. Есть два способа
собрать её самому.

### Способ А — без Android Studio, через GitHub Actions (проще всего)

Сборка идёт в облаке на серверах GitHub, тебе нужен только браузер.

1. Зарегистрируй бесплатный аккаунт на github.com, если его ещё нет.
2. Создай новый пустой репозиторий (New repository), можно приватный.
3. На странице репозитория: Add file → Upload files → перетащи туда
   **всё содержимое** папки `CameraOverride` (включая скрытую папку
   `.github` — если её не видно в проводнике, включи показ скрытых
   файлов/папок в настройках ОС перед перетаскиванием).
4. Закоммить (Commit changes) прямо в ветку `main`.
5. Перейди во вкладку **Actions** репозитория — workflow "Build APK"
   запустится автоматически после пуша (или нажми Run workflow вручную,
   если не запустился сам).
6. Подожди 2–5 минут, пока сборка не станет зелёной (✅).
7. Открой завершённый запуск → внизу страницы раздел **Artifacts** →
   скачай `CameraOverride-debug-apk` (это zip с APK внутри).
8. Перекинь APK на телефон (почта себе, облако, ADB) и установи.

Не бойся, что ROOT/секреты — тут ничего не палится, workflow просто
собирает публичный код, ключей/паролей в проекте нет.

### Способ Б — классический, через Android Studio

1. Установи **Android Studio** (последнюю стабильную версию).
2. Открой эту папку (`CameraOverride`) как проект — Android Studio сама
   подтянет Gradle wrapper и SDK при первом открытии.
3. Дождись синхронизации Gradle (может попросить установить Android SDK
   Platform 34, если его ещё нет).
4. Build → Build Bundle(s) / APK(s) → Build APK(s).
5. Готовый APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

## Установка на телефон

1. Скопируй APK на телефон, установи (разреши установку из неизвестных
   источников при необходимости).
2. Открой **LSPosed Manager** → «Модули» → найди `CameraOverride` (или
   "CameraOverride (IG 0.5x fix)") → включи.
3. Зайди в его scope-настройки и вручную поставь галочку на **Instagram**
   (модуль не объявляет scope программно — выбираешь сам в LSPosed Manager).
4. **Перезагрузи телефон** (LSPosed внедряет хуки на старте процесса —
   простого force-stop Instagram обычно недостаточно, нужен полный ребут,
   либо как минимум ребут Zygote, если твой LSPosed это поддерживает).
5. Открой Instagram → камера для Stories/моментального снимка должна
   теперь открываться на 0.5x (более широкий угол обзора — верный признак,
   что сработало).

## Если не заработало

- Проверь лог через **LSPosed Manager → логи** — там будут строки
  `[CameraOverride] ...`, если хук вообще сработал для процесса Instagram.
  Если строк нет — модуль не был подключён к процессу (проверь scope и
  перезагрузку).
- Если строки в логе есть, но камера всё равно не открывается / крашится —
  возможно, Instagram запрашивает `CameraCharacteristics` по ID "0" где-то
  ещё до вызова `getCameraIdList()`, либо использует иной механизм выбора
  камеры. В этом случае нужно смотреть логи крэша (`adb logcat`) и
  дорабатывать хуки под конкретное поведение установленной у тебя версии
  приложения — гарантировать 100% работу заранее нельзя, версии Instagram
  меняют внутреннюю логику камеры без предупреждения.
